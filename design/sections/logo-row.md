## Use for

The proof strip: a centred heading, a stat line, a row of outlined logo slots, and the caption that explains them. The slots are EMPTY by default and that is the component's argument, not a missing feature — the strip asserts that named proof only appears with consent, so a `LogoSlot` renders a child only when given one and no fabricated customer mark ever goes in a slot. Every colour is a mode-aware role, so the strip survives both the dark page and a cream `light` ancestor with no `onLight` prop.

## Use for

The halftone field a panel floats on: a container that paints one of the three real site textures (`card1/2/3_bg.webp`) and insets its child by a percentage of the track width. The percentage is the whole design — the live panel is 84–92% of its container, and only a percentage holds that proportion at every width; a fixed padding turns the field into a coloured border on a short wide card. It is the narrowest of the package's four texture tools: field behind a mock inside a feature row, as opposed to `HeroBackdrop` (hero strip), `DitheredMedia` (whole hero composition) and `DitherOverlay` (the raw layer).

## Watch for

| note | via |
| --- | --- |
| `minHeight: '22rem'` is set as an **inline style** and there is no `style` prop on `SectionBackdropProps`, so no Tailwind `min-h-*` in `className` can beat it — inline styles win and twMerge cannot reach them. Making it shorter needs one small prop addition to this file (a `minHeight` or a passthrough `style` prop); say so rather than fighting it from the call site. | `inline style` |
| `padding: ${inset}%` applies to all four sides, and CSS resolves percentage padding against the container's **width** in both axes — so a wide, short container gets large vertical padding from a small `inset`. The 22rem floor exists because without vertical room the texture only shows left and right, which is the border failure again in the other axis. | `prop SectionBackdrop.inset` |
| Children are flex items on a `flex items-center` root, not layers: exactly one node goes in the `relative w-full` z-1 wrapper. And there is no overlay element in this file — the texture is a CSS `background-image` on the container itself, so the header comment's "aria-hidden, pointer-events-none" describes `FeatureRow`'s sheen, not anything here to restyle. | `prop SectionBackdrop.texture` |
| Texture URLs are resolved with `new URL('../../assets/…', import.meta.url)` on purpose, so a bundler rewrites them and consumers need not copy files into their own `public/`. ## Constraints

From `machine/components.yaml` (`sections.SectionBackdrop`).

| prop | allowed |
| --- | --- |
| `texture` | `journey`, `github`, `schema` |
| `src` | string — explicit URL, for a consumer with its own artwork |
| `inset` | number — percent of width, default 6 |

- `inset` is a PERCENTAGE and not a spacing step. The live panel is 84-92% of its container, and a percentage holds that proportion at every track width by construction. A fixed padding was tried and turns the field into a coloured BORDER on a short wide card. Do not override it with a padding utility.
- minHeight is 22rem and is inline, so no class beats it. The live container is square: without vertical room the texture only shows left and right, which is the border failure again in the other axis.
- Textures are resolved with new URL(…, import.meta.url), never as /img/card1_bg.webp. A consumer installing the package has no public/img and a bare path renders as a missing image everywhere but the prototype. Same mechanism as ArtFrame, which names the same three assets gh/db/jr against journey/github/schema here.
- Decorative throughout — aria-hidden, pointer-events-none, content lifted above. It is a field for an artifact, not a container for copy.
- NOT a band-wide ground behind a copy row. Recorded twice on the marketing site, both times as a correction: a SectionBackdrop behind a copy column washed the whole band out. It is right for a full-width artifact band where the field IS the band — pair it with the full width, because capping it at the prose measure spends the 6% inset twice.

## What binds this module

- **Polarity `inherits`.** It puts no theme class on its own root, so it takes the page. Place it on a light fill and the `light` class is yours to add, or its mode-aware tokens resolve to their DARK values against that fill — measured at 1.07:1 on rendered pixels.
- **`chrome.*` is invariant.** This module is in the fixed-dark world, so the distinction bites here: `chrome.*` never inverts and belongs only on a surface that never flips. Anything on a surface that follows the theme uses `text.*` / `surface.*`. The two share their dark values, so the wrong pick looks correct until someone opens light mode.
- **Content is props.** This section hardcodes no copy; the page supplies it.

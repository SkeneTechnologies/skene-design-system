## Use for

A real semantic `<table>` for capability comparison — one row per claim, one column per approach, with your column picked out. The featured column is washed in the head *and* every body cell so it reads as one continuous object top to bottom, and the header additionally turns peach so its identity is stated once in words rather than only in colour. The whole component is really the pairing of `min-width: 820px` on the table with `overflow-x: auto` + `tabIndex={0}` on the wrapper: a comparison that reflows into stacked cards stops being a comparison, so on narrow screens it keeps its shape and scrolls sideways instead.

## Watch for

| note | via |
| --- | --- |
| Never put `min-w-*` on the wrapper or `overflow` on the table. The source calls this out: swap them and the page body scrolls horizontally instead of the panel. `className` lands on the wrapper, so a stray `min-w` there is the easy mistake. | `className` |
| `featuredIndex` indexes `columns` *including* the leading row-header column, while body cells compute `featuredIndex === i + 1`. That is intentional (one index space for both) but it means `featuredIndex={0}` washes the header cell and nothing in the body — a half-marked column. Valid values start at 1. | `prop ComparisonTable.featuredIndex` |
| Column widths are `w-[40%]` for the row header and `w-[20%]` for every other column regardless of how many there are. It is tuned for three answer columns; five answer columns declares 140% and the browser renegotiates it. | `prop ComparisonRow.header` |
| `featuredIndex` reaches rows by `cloneElement` over `Children.toArray`, not by context (deliberately — `createContext` would drag this static table across the client boundary to pass one number). Rows must be direct, valid element children: wrap them in a Fragment or a wrapper component and the injection silently stops. Similarly, the last-row rule removal is `[&>tr:last-child>*]:border-b-0` on the `<tbody>`, so a `<tfoot>` or an extra element in there breaks it. | `prop ComparisonTable.featuredIndex` |
| The accessibility contract is load-bearing and easy to erode: `<th scope="col">` in the head, `<th scope="row">` per row, and glyph cells carrying an `sr-only` word — a cell whose entire content is `aria-hidden` reads as "no data", not "no". Keep `label` populated when you pass custom markers. | `prop TableMarker.label` |

## What binds this module

- **Polarity `inherits`.** It puts no theme class on its own root, so it takes the page. Place it on a light fill and the `light` class is yours to add, or its mode-aware tokens resolve to their DARK values against that fill — measured at 1.07:1 on rendered pixels.
- **`chrome.*` is invariant.** This module is in the fixed-dark world, so the distinction bites here: `chrome.*` never inverts and belongs only on a surface that never flips. Anything on a surface that follows the theme uses `text.*` / `surface.*`. The two share their dark values, so the wrong pick looks correct until someone opens light mode.
- **Content is props.** This section hardcodes no copy; the page supplies it.
